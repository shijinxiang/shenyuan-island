# 海岸生存资产与动作

游戏资源目录：`游戏/assets/survival/`。建模参考为 Terra 生成的 `素材/03_参考图与资料/生存与海岸生态/海岸生存_复合参考.png`，动作对照同目录 `鳄鱼_动作关键帧参考.png` 和三个参考 GIF；动作已在真实 Blender 骨骼上实现并另行渲染，没有把参考帧当成模型动作交付。

## 家具与补给

| GLB | 尺寸 X×Y×Z（米） | 结构 / 接口 |
|---|---|---|
| bed | 1.229×0.950×1.930 | 木床、床垫、枕头、绿毯；床头朝 -Z |
| chest | 1.150×0.654×0.609 | `ChestBase` 与 `LidPivot/ChestLid`；有真实内部空间 |
| cabin_lamp | 0.373×0.601×0.362 | 木框暖灯；暖色发光材质，灯光由玩法添加 |
| food_bundle | 0.418×0.258×0.320 | 叶片包裹及绑绳 |
| medical_kit | 0.360×0.329×0.194 | 米白补给包、提手及绿色识别牌 |

箱盖节点路径 `LidPivot`，局部铰点 `(0,0.535,-0.285)`，绕 X 轴旋转；关闭为 0，开启为 -1.3 弧度。小屋地板局部 Y=0.65，已有床位与箱位可以直接放入。床模型含绑绳后的真实外包围尺寸仍小于预留 1.3×1.95m。

灯模型是几何和自发光材质；建议点光源局部位置 `(0,0.25,0)`，范围4.5m，暖色 `#ffd58c`。交互关闭时应关闭实际灯光，并同步将 `Warm luminous diffuser` 的 emission 关闭。灯脚倾斜几何的最低点为 -0.0013m，其余家具及补给最低点为0。

## 咸水鳄鱼

`saltwater_crocodile.glb`：长2.91m、宽1.085m、高0.560m；朝 +Z，鼻尖 Z=+1.34、尾尖 Z=-1.57，脚底 Y≈0。单个蒙皮网格约2356三角面，19骨骼：Root、Body、Head、Jaw、三段尾、四组大腿/小腿/脚掌。可辨鳞甲、腹甲、金色眼睛、牙齿和脚爪。

- 骨架路径：`CrocodileRig/Skeleton3D`
- 网格路径：`CrocodileRig/Skeleton3D/CrocodileMesh`
- 动画播放器：`AnimationPlayer`

| 动作 | 时长 | 循环 | 实现 |
|---|---:|---|---|
| Idle | 2.0s | 是 | 呼吸、轻尾摆与微开颌 |
| Crawl | 1.2s | 是 | 对角腿交替，两段腿IK烘焙，接地后推与抬脚回摆 |
| Swim | 1.6s | 是 | 四腿收拢，三段尾水平相位摆动 |
| Attack | 0.9s | 否 | 抬头张颌、短促体部前冲，约0.42s闭合咬合 |
| Eat | 1.4s | 是 | 反复小幅咀嚼和头部动作 |
| Death | 1.3s | 否 | 向侧面倒下，终帧保持倒地 |

Root 始终无平移；Crawl/Swim 等循环原地播放。glTF 不保存播放循环方式，接入时从 `manifest.json` 设置 Godot `loop_mode`。Attack 和 Death 不能循环。

**防滑步接入：**Crawl 每周期60%为接地后推，接地步幅0.38m，1倍播放对应水平速度0.5277778m/s。移动时令 `AnimationPlayer.speed_scale = 实际水平速度 / 0.5277778`；停下时切 Idle。仅制作原地动画无法控制游戏AI移动速度，必须同步这两个量。骨骼预览检查接地脚掌高度、对角步态及尾部摆动。

`Crawl_actual.gif`、`Swim_actual.gif`、`Attack_actual.gif` 是真实骨骼动作渲染，640×360，约24fps。Attack GIF 为方便观看会循环播放并在末帧停留0.6s；模型里的 Attack 动作仍为0.9s非循环动作。

## 源文件与验证

- `海岸生存_模型与动画.blend`：家具、补给与完整鳄鱼骨架/动作源工程。
- `build_survival_assets.py`：重建程序，复用相邻 `农耕与伐木/build_farming_assets.py` 的基础几何函数。
- `render_animation_previews.py` 与 `package_gifs.py`：实际动作渲染和 GIF 封装。
- `家具与补给_模型总览.png`、各动作 PNG：可视检查。
- `godot_validation.json`：Godot 4.7.2 独立项目验证报告；六个 GLB 均成功导入并实例化，具 UV/材质，箱盖路径正确，19骨架与六动作存在，Root无位移，Attack颌部有实际变形。
- `animation_preview_validation.json`：实际采样动作与接地脚掌高度检查。

未改游戏脚本、主场景和 project.godot。移动、碰撞、攻击判定、储物、休息和灯光交互由玩法系统负责。
