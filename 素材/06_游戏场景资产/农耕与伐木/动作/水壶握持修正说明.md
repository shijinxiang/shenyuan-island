# Watering 右手握柄修正

更新游戏资源 `游戏/assets/characters/C01_watering.res`，接口保持 `Watering`、5.6 秒、53 条轨道、不循环。原左手辅助姿势和躯干/手臂动作保留。

参考了用户实际游戏截图，检查了 `island_farming.gd` 的 `_update_held_tool()` 和现有 `watering_can.glb`。旧实现的问题包括原动作指骨并非全程抓握，以及水壶使用独立的世界 UP/forward 倒水朝向，导致提手与手掌方向分离。

## 指骨与腕部

四指改为围绕真实提手顶横杆的 C 形，拇指从相反侧合拢。顶横杆局部 X 范围约 −0.10 至 0.09 米，截面外接半径 0.026 米。15 个右指骨在整个片段维持同一手掌局部抓握形状。

为避免开头和结尾垂挂的壶身进入大腿，保留最多 18 度的端点倾斜。最新朝向修正使 1.0–4.6 秒壶本体前轴朝前下倾 55 度，喷嘴实际出口轴向下 10 度。右前臂仅做必要的最小旋转，最大约 32.3 度、腕位置最大变化约 10.6 厘米，用来把腕弯曲限制在 80 度以内；右上臂、肩、左臂不变。15 指骨抓握形状不变。

## 运行时校准（Godot）

推荐从 `RightHand` 骨骼全局变换计算，避免把提手中心直接放在原来的 Hand→Middle1 0.65 插值处。

```gdscript
var hand_global: Transform3D = skeleton.global_transform * skeleton.get_bone_global_pose(skeleton.find_bone("RightHand"))
var calibration := Basis(Vector3(1, 0, 0), Vector3(0, -1, 0), Vector3(0, 0, -1))
var can_basis := hand_global.basis.orthonormalized() * calibration
var grip_center := hand_global * Vector3(0, 0.090, -0.048)
var can_grip := Vector3(0, 0.55, 0)
model.global_transform = Transform3D(can_basis, grip_center - can_basis * can_grip)
```

最新 `calibration` 等价于手掌局部 X 轴旋转 PI，Godot Quaternion 的 `(x,y,z,w)` 为 `(1,0,0,0)`。矩阵必须右乘在骨骼基底之后。无需再叠加旧世界 UP/forward/sin 倒水角或水壶额外 Y 轴 PI/2；倒水朝向由已修正的右腕动画产生。旧 `diag(-1,-1,1)` 把壶嘴指向了人物后方，已废弃。

若保留 `_hand_center("RightHand", "RightHandMiddle1")` 的 0.65 插值锚点，要再加上手掌基底乘局部偏移 `(-0.001696, 0.025071, -0.050862)`，才对应同一提手中心。直接采用上面的 `RightHand` 公式更明确。

建议浇洒特效窗口仍为约 1.0–4.6 秒。本修正资源只覆盖 Watering 动画；若游戏要求选择水壶后 Idle/行走也握柄，运行时应沿用 `watering_grip_calibration.json` 中 15 个指骨的局部旋转。JSON 指骨 Quaternion 排列是 Blender 的 `(w,x,y,z)`，用于 Godot 时要转换成 `(x,y,z,w)`。

- 原角色与原水壶组合验证，未替换成简化手掌或替代工具。

原角色完整动作文件、`C01_locomotion.glb`、水壶模型和游戏脚本未修改。
