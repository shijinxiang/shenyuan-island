# 农耕与伐木模型库

按 `素材/03_参考图与资料/农耕与伐木/农耕伐木_复合参考.png` 建模，并参照已接入棕榈树的低多边形自然配色。

## 可接入文件

游戏资源位于 `游戏/assets/farming/`：

- `axe.glb`、`hoe.glb`、`watering_can.glb`
- `log.glb`、`stump.glb`、`soil_plot.glb`
- `turnip_stage_0.glb` 至 `turnip_stage_3.glb`
- `tomato_stage_0.glb` 至 `tomato_stage_3.glb`
- `pumpkin_stage_0.glb` 至 `pumpkin_stage_3.glb`
- `soil_dry.tres` / `soil_wet.tres` 及对应 albedo / roughness PNG。
- `manifest.json`：完整三角面数、顶点数、材质、边界、握点及贴地说明。

每个 GLB 为单个合并网格，多材质按 surface 分组。单位为米，Godot Y-up，所有模型最低点 y=0、网格节点变换为 identity。原木沿 Z 轴放平。作物四阶段使用独立几何，分别为出苗、长叶、未成熟果实/开花、可收获成熟期。成熟萝卜有双色球根，番茄有多个红果，南瓜有八瓣起伏果体。

工具握点（模型局部 Godot 坐标）见 `tools.NAME.grip`：斧 `[0,0.32,0]`，锄 `[0,0.38,0]`，壶 `[0,0.55,0]`。

土块为封闭体积网格，约 1.4m × 1.4m，最高约 0.122m。顶面有 29×29 顶点、五列真实起伏沟垄和细碎块面，边缘连接底面。干土嵌入纹理；湿土材质可在运行时替换。贴地时对每个顶点的 y 加上其 x/z 处地形采样高度，保留原始局部 y（体积厚度），再重算网格法线。无需将底面压成同一平面。底面和顶部均为真实几何，不能以单平面替代。

## 可重建源文件

- `build_farming_assets.py`：Blender Python 建模、纹理生成、GLB 导出及预览生成程序。纹理为独立程序生成，不是参考图裁切。
- `农耕与伐木_模型库.blend`：每项资产独立 collection，均保留原点。
- `农耕与伐木_预览场景.blend` 与 `农耕与伐木_模型总览.png`：仅用于检查和展示；预览排布没有写入游戏 GLB。

重建命令：

```powershell
& 'D:\blender\Blender 5.2\blender.exe' --background --python 'D:\浪费GPT额度\小温的游戏\素材\06_游戏场景资产\农耕与伐木\build_farming_assets.py'
```

程序只覆盖本农耕资产及本源目录的生成文件，不访问用户打开的 Blender 场景。

## 验证

验证脚本集中在 `工具/资产核验/农耕与生存/`，使用游戏工程中的实际资源检查模型。历史验证使用 Godot 4.7.2 完成18项GLB导入和实例化，覆盖网格变换、落地、顶点、UV、材质、土块厚度和干湿纹理，结果保存在本目录的 `godot_import_validation.json`。

早期独立验证工程已收入 `归档/06_本轮制作备份与过程脚本.zip`，原路径和文件摘要见归档索引。新验证可通过 `verify_assets.gd` 指定输出路径，运行方法见工具目录说明。

本目录只交付资产；购买、装备、砍树、浇水、生长计时、收获和地形贴合由游戏玩法实现。
